# Модель безопасности

MsgCrypt считает WhatsApp и Telegram недоверенными транспортами. Они видят
метаданные: аккаунты, собеседников, время, размеры и количество carrier-пакетов.
Содержимое новых MsgCrypt-сообщений защищено AES-256-GCM, а пакеты подписаны
ECDSA P-256.

## Гарантии

- конфиденциальность текста после подтверждённого ECDH-обмена;
- целостность и аутентичность пакета после проверки identity key;
- защита от повторной выдачи DATA-пакетов счётчиком и message UUID;
- изоляция ключей по аккаунтам и диалогам;
- отсутствие plaintext fallback при отправке.

## Не гарантируется

- сокрытие метаданных и факта использования MsgCrypt;
- безопасность скомпрометированного/рутованного устройства;
- анонимность;
- совместимость с официальными клиентами для расшифровки;
- защита до ручного сравнения отпечатков;
- стабильность неофициального WhatsApp Web API.

Исходный CryptoLayer использует raw ECDH secret напрямую как AES-ключ.
MsgCrypt v1 добавляет HKDF-SHA256, привязку к session ID, счётчики и жёсткие
лимиты разбора. Поэтому это перенос дизайна, но намеренно не byte-level
совместимый wire format с Python-библиотекой.
